❓ Garage Worm — Help

🚗 Vehicles

Click ➕ Vehicle to add a car. Fill in year, make, model, and optionally trim, engine type, mileage, notes, and photos. Switch between vehicles using the tabs. Click the ✎ Edit button in the vehicle detail line to update any field or add/remove photos. Vehicle photos appear as clickable thumbnails under the tabs.

🏁 Odometer

The yellow odometer bar lets you update your current mileage without creating a service record. This keeps consumable tracking accurate between services. Just type the new reading and hit Update.

📋 Service Records

Click ➕ Add Record to log a service. Each record has a date, category, service description, mileage, cost, notes, and optional photo attachments. Click ✎ on any record to edit it. Click 🔧 to turn a record into a tracked consumable (pre-fills the name, date, and mileage — just add the replacement interval). Click any photo thumbnail to view full-size in the lightbox.

📐 Estimated Mileage

When adding an old record where you don't remember the exact mileage, check Estimate from surrounding records. This calculates the midpoint between the nearest records before and after the date you entered. Set the date first, then check the box.

🔧 Consumables

Switch to the Consumables tab to track parts with replacement intervals. Each consumable can be tracked by mileage, time (months), or whichever comes first. Cards show color-coded progress bars — green (good), orange (due soon at 75%), red (overdue). Hit ↻ to mark one as replaced at the current date and odometer reading. Consumables are independent — deleting the original service record will not remove the consumable.

🔩 Tools & Tips

Each consumable has a "Tools & Tips" field where you can record wrench sizes, torque specs, part numbers, fluid types, procedures, or anything you'll need next time. This shows on the consumable card and is included in exports.

🗑️ Deleting

All deletes (records, consumables, vehicles) go through a confirmation screen. This is intentionally dramatic to prevent accidental deletions. Vehicles delete all associated records and consumables. Records can be deleted without affecting any consumables created from them.

📥 Exporting Your Data

Click 📥 Export to download your entire database as a dated JSON file (e.g. garageworm-2026-05-11-1432.json). This includes all vehicles, records, consumables, photos, and tools data. Each export has a unique timestamp so multiple exports per day don't overwrite each other.

📤 Importing Data

Click 📤 Import and select a previously exported JSON file. This replaces your current database entirely. The status bar at the bottom shows the source — "browser cache" or the imported filename.

⚠️ Keep Your Export Safe

All data lives in your browser's localStorage, which can be lost if you clear browser data, switch browsers, or reinstall your OS. Export regularly and keep the JSON file somewhere safe — cloud drive, USB, or any backed-up location. The export is your only recovery path.

🌙 Dark Mode & 🔊 TTS

Toggle dark mode with the sun/moon switch. Toggle text-to-speech with the speaker switch — when off, all voice output is silenced. Both preferences are saved between sessions.

💾 Storage Notes

Photos are resized to 1200px max width. Browser localStorage typically allows 5-10MB. If storage fills up, export and clear old records with large attachments.
